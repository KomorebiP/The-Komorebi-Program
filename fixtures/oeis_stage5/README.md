# Selected official OEIS excerpts for Stage 5

Source: The Online Encyclopedia of Integer Sequences, OEIS Foundation Inc., CC BY-SA 4.0.

Repository: https://github.com/oeis/oeisdata, revision `a9e6e3a6a7b6ad00375d1a87a9bd5cc50885095e`.

These files contain only one verbatim `%S`, one selected `%F`, and one `%O` field per record. Other fields and additional source terms are omitted. `plan.json` operates on the excerpts and records the original blob and formula line. `full_source_plan.json` requires complete official records at the same revision, verified by their Git blob hashes and original formula line. The excerpt files intentionally fail the full-record plan. No source-supplied program is executed.
