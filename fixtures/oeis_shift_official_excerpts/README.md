# Selected OEIS source excerpts

The seven .seq files here are **excerpts**, not full OEIS records. They retain the original I, S/T/U, N, one selected F, and O fields, obtained from the official oeisdata repository at commit `a9e6e3a6a7b6ad00375d1a87a9bd5cc50885095e`. `plan.json` records the full-file Git blob IDs and original formula line numbers. The locally proved conditional overlay uses the excerpt SHA-256 values. `full_source_plan.json` requires the original full-file Git blob IDs and can be replayed on a checkout of that revision. No claim is made about all other formulas in the complete entries.

Source: The Online Encyclopedia of Integer Sequences, OEIS Foundation Inc., https://oeis.org/ and https://github.com/oeis/oeisdata. Source excerpts retain original contributor attribution and are licensed CC BY-SA 4.0 (https://creativecommons.org/licenses/by-sa/4.0/). Komorebi code and independently derived algebraic results are separate from the source excerpts.
