# Graph and array formula atlas

**Author: Komorebi P.**

537 records in 17 family groups, including 462 retained records and 75 derived nonbipartite models. The retained four formula catalogs and three theorem files are byte-identical to the source archives; the generator validates their SHA-256 hashes before rendering. The 288 core entries include full binomial-residue expansions; the 168 array and six other graph formulas preserve their original model and OEIS evidence. Ten tree IDs overlap the graph supplement. The broader Sequence Library remains separate.

Node.js is required to run the exact all-index audit and generate the transfer data during each atlas build. Build a standalone preview with `python tools/graph_formula_atlas.py --preview /tmp/graph-formula-atlas`. Run `python -m unittest discover -s tools -p 'test_graph_formula_atlas.py'`. The preview lacks the full reader shell and MathJax runtime; the reader site supplies both. Original OEIS material is attributed to OEIS Foundation Inc. (CC BY-SA 4.0); independent code follows the host code license. No independent Lean certification, novelty claim or corpus admissions.

Deployment audit: the original reader build completed, but the site accessibility gate rejected the calculator/search controls because they lacked explicit label associations. Each input and selection control now has an explicit label and unique identifier; the static regression test checks all 291 controls. The independent Python and JavaScript residue evaluations each reproduced 18,460 stored coefficients. All 462 index links and 15 family routes were checked in the local preview. Local browser navigation was blocked by the environment; visual browser verification is not claimed. Deployment is subject to the existing reader workflow gates.

## Exact transfer continuation

Run `node tools/verify_graph_formula_atlas_exact.js` to check 288 all-index rational/residue identities, 1,752 lanes, reduced denominators, periods and a corrupted-coefficient rejection control. Run `node tools/compile_graph_atlas_transfers.js transfer-index.json` to export the 288 core models, 16 equivalence groups, 60 exact transfer identities, 75 nonzero complements and 11 zero complements. The 75 complements include 74 distinct rational functions not present among the original 262. The compiler independently compares 80 coefficients per nonzero complement (6,000 comparisons). The atlas build generates the JSON download and two additional family pages with signed-residue calculators, and preserves the original seven source hashes. Counts are algebraic consequences of the retained combinatorial models; no new OEIS bindings or mathematical priority claims follow. The expanded branch requires a fresh end-to-end site and browser audit before release.
