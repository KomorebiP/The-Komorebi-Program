## Exact array calculator continuation

All 168 retained array formulas are parsed into restricted expression trees or explicit finite-state construction descriptors. Run `node tools/compile_graph_array_atlas.js array-index.json` to reproduce 499 independent cell-frontier comparisons (indices 1 through 3), including the first index of every model. Five costly evaluations exceed the browser work budget and are explicitly reported as unevaluated. Invalid index and resource-budget rejection controls pass. The site now offers 537 exact calculator implementations, covering every record. These tests compare the stated mathematical constructions, not independently retrieved OEIS terms. Browser interaction and the complete expanded reader build remain subject to CI and release checks.
